# 固定输入与统计规则

- `obscodes_snapshot.dat`：原项目使用的 MPC 台站目录原样副本；初始外部文件路径和 SHA256 可查首次审计。目录年份和精度不等同于当前完整目录。
- `mpc_supplement.json`：2026-10-19 从 MPC 官方目录索引核对的问题站码，保存经度与视差常数。全目录在线下载不可用；不宣称完成 MPC 全量实时同步。各站国家由明确台站身份给定。
- `ne_110m_admin_0_countries.geojson`：复用原项目缓存的 Natural Earth 110m 边界资料，https://www.naturalearthdata.com/ 。用于制图与标记为推断的点包含归属；不能处理全部边界、沿海与小岛细节。
- `counting_policy.json`：明确团队来源白名单、非卫星排除、整表替代及精确时刻重叠规则。优先保留 Camargo 2022 / um0138 的 Gaia EDR3 重归算，而非将最新版本整体删除。

主图展示“已知重叠调整后的目录位置条目”；“卫星目录累计条目”保留在 data/satellite_statistics.csv 的累计字段中，不再另出图。两者都包含仍待建立对应关系的重归算和不同观测单位，不等于已认证的唯一曝光数。所用输入和所有排除结果有独立清单，未知记录不会分摊给已知站点。
