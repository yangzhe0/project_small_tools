# 人脸笑容识别系统 (Smile Recognition System)

这是一个基于 Python、PyQt5 和 MediaPipe 的实时人脸笑容识别系统。它能够通过摄像头捕捉面部画面，并实时分析是否在微笑。

## 功能特点

*   **实时检测**：使用 MediaPipe Face Mesh 进行高精度的面部关键点检测。
*   **中文界面**：全中文 GUI，操作直观。
*   **灵敏度调节**：可以通过滑块调整笑容检测的灵敏度。
*   **拍照功能**：支持手动抓拍精彩瞬间。
*   **跨平台**：兼容 Windows 和 macOS。

## 安装说明

1.  确保已安装 Python 3.8 或更高版本。
2.  安装依赖库：

```bash
pip install -r requirements.txt
```

## 使用方法

1.  运行程序：

```bash
python main.py
```

2.  点击 **“启动摄像头”** 按钮开始检测。
3.  对着摄像头微笑，状态栏会显示 **“😄 检测到笑容!”**。
4.  如果检测不准确，可以拖动 **“灵敏度调节”** 滑块：
    *   向左拖动（数值变小）：更容易检测到笑容（可能误报）。
    *   向右拖动（数值变大）：需要更明显的笑容才能触发。
5.  点击 **“手动拍照”** 保存当前画面。

## 目录结构

*   `main.py`: 程序入口。
*   `core/`: 核心算法模块。
*   `gui/`: 图形界面模块。
*   `requirements.txt`: 项目依赖。

## 技术栈

*   **GUI**: PyQt5
*   **计算机视觉**: OpenCV, MediaPipe
*   **语言**: Python
